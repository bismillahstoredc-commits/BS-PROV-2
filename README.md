# BS PRO v2 (GitHub Pages সংস্করণ)

সার্ভার ছাড়া অ্যাপ। ডেটা থাকে আপনার ফোন/কম্পিউটারের ব্রাউজারে (IndexedDB), আর একাধিক ডিভাইসে শেয়ার করতে একটি **প্রাইভেট GitHub repository**-তে সিঙ্ক হয়। ইন্টারনেট না থাকলেও সব কাজ চলে, নেট এলে নিজে থেকে সিঙ্ক হয়।

## ধাপ ১: অ্যাপ হোস্ট করুন (GitHub Pages, ফ্রি)
1. GitHub-এ নতুন repository খুলুন, নাম যেমন `bspro-app` (এখানে শুধু অ্যাপের কোড থাকবে, ব্যবসার ডেটা নয়; ফ্রি Pages-এর জন্য এটি Public হতে হবে)।
2. এই ফোল্ডারের **সব ফাইল** (index.html, core.js, screens.js, screens2.js, scan.js, brand.js, app.js, sw.js, manifest.json, icons ফোল্ডার) আপলোড করুন।
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save।
4. কয়েক মিনিট পর `https://আপনার-ইউজারনেম.github.io/bspro-app/` লিংকে অ্যাপ খুলবে।

## ধাপ ২: ডেটা রাখার প্রাইভেট repository
1. আরেকটি নতুন repository খুলুন, নাম যেমন `bspro-data` → **Private** নিন → "Add a README file" টিক দিন।
2. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate:
   - Repository access: শুধু `bspro-data`
   - Permissions → Repository permissions → **Contents: Read and write**
   - টোকেনটি কপি করে রাখুন (আর দেখা যাবে না)।

## ধাপ ৩: অ্যাপে সংযোগ
- প্রথমবার অ্যাপ খুলে "নতুন ব্যবসা তৈরি করুন" → সেটিংস → ক্লাউড সিঙ্ক-এ ইউজারনেম, `bspro-data`, ব্রাঞ্চ (`main`), টোকেন দিয়ে "সংযোগ পরীক্ষা ও সেভ"।
- অন্য ফোন/কম্পিউটারে: লিংক খুলে **"আগের ডেটা GitHub থেকে ফিরিয়ে আনুন"** → একই তথ্য দিন → নিজের ইউজারনেম/পাসওয়ার্ডে লগইন। পাসওয়ার্ড শুধু প্রথমবার লাগবে, লগআউট না করলে আর চাইবে না।
- ফোনে Chrome-এ মেনু → "Add to Home screen" দিলে অ্যাপের মতো আইকন হবে।

## ১০–২০ বছরের জন্য
- ব্রাউজারের IndexedDB-তে প্রতিটি ইনভয়েস আলাদা রেকর্ড, তাই ডেটা বাড়লেও ধীর হয় না।
- GitHub-এ ডেটা **মাস অনুযায়ী আলাদা ছোট ফাইলে** (`docs-2026-09.json` ইত্যাদি) জমা হয়, তাই একটি বিশাল ফাইল কখনো তৈরি হয় না।
- স্টক ও বকেয়া সংরক্ষিত সংখ্যা নয়, লেনদেন থেকে হিসাব হয়; তাই একাধিক ডিভাইস একসাথে কাজ করলেও স্টক/বকেয়ায় গরমিল হয় না।
- প্রতি মাসে একবার সেটিংস → "ব্যাকআপ ডাউনলোড" করে রাখুন (নিরাপত্তার জন্য)।

## সতর্কতা
- টোকেন প্রতিটি ডিভাইসের ব্রাউজারে সংরক্ষিত থাকে; অন্যকে ডিভাইস দেবেন না, হারালে GitHub থেকে টোকেন বাতিল করুন।
- একই ইনভয়েস দুজন একই সময়ে এডিট করলে যার সেভ পরে হবে সেটিই থাকবে।
- ডেটা repository অবশ্যই Private রাখুন।

## নতুন ফিচার (বারকোড, পাইকারী, পেমেন্ট)
- **ক্যাটাগরি / একক** মেনু থেকে তালিকা বানান; পণ্য এন্ট্রিতে ড্রপডাউন থেকে বাছাই (পাশে + দিয়ে দ্রুত নতুন যোগ)।
- **পণ্য এন্ট্রি:** বারকোড (স্ক্যানার/ক্যামেরা 📷/টাইপ/অটো জেনারেট), পাইকারী মূল্য ও সর্বনিম্ন পরিমাণ।
- **বিক্রয়/ক্রয় পেজ:** বারকোড স্ক্যানার (কীবোর্ড-টাইপ স্ক্যানার) বা মোবাইল ক্যামেরা (📷 স্ক্যান) দিয়ে পণ্য যোগ; একই বারকোড আবার স্ক্যান করলে পরিমাণ +১।
- **পেমেন্ট:** ক্যাশ / ব্যাংক / বাকি / মিশ্র (আংশিক ক্যাশ + ব্যাংক + বাকি)। ছাড় ৳ বা % এ। মালিকের জন্য বিক্রয়ে আনুমানিক লাভ দেখায়।
- ক্যামেরা স্ক্যান Chrome (Android/PC) এ সরাসরি চলে; অন্য ব্রাউজারে প্রথমবার ইন্টারনেট লাগতে পারে। HTTPS (GitHub Pages) লিংকে খুলতে হবে।

## PWA (মোবাইল ও কম্পিউটার)
- লোগো ও "BS PRO" ওয়ার্ডমার্ক অ্যাপের হেডার, মেনু, লগইন, ব্রাউজার ট্যাব, ইনভয়েস ও ইনস্টল আইকনে বসানো আছে।
- **Android/Chrome ও কম্পিউটার (Chrome/Edge):** লিংক খুলে মেনুর **"📲 অ্যাপ ইনস্টল করুন"** (বা ঠিকানার পাশের ইনস্টল আইকন) চাপুন।
- **iPhone (Safari):** শেয়ার → Add to Home Screen।
- হোম স্ক্রিনের আইকন চেপে ধরলে **নতুন বিক্রয় / নতুন ক্রয় / পণ্যসমূহ** শর্টকাট পাবেন (Android/কম্পিউটার)।
- আপডেট দিলে `sw.js`-এর `bspro2-v3` সংখ্যাটি বাড়িয়ে দিন, যাতে পুরনো ক্যাশ সরে যায়।

## ইউটিলিটি → অ্যাকাউন্ট রিসেট
শুধু মালিক দেখতে পান। পাসওয়ার্ড ও RESET লেখা লাগে, রিসেটের আগে অটো ব্যাকআপ নামে। "শুধু লেনদেন" বা "পূর্ণ রিসেট" বেছে নেওয়া যায়। সিঙ্ক চালু থাকলে অন্য ডিভাইসেও একই রিসেট প্রযোজ্য হয়।
